
# CzechVisage

Czech translation of Visage version 4.6.1

## Popis
Tento modul poskytuje českou lokalizaci pro Visage verze 4.6.1. Obsahuje překlady základních textů aplikace.

## Instalace
Pro instalaci modulu obvyklým způsobem můžeš použít následující odkaz ve Foundry VTT:

```
https://raw.githubusercontent.com/Lethrendis/CzechTranslationVisage/main/module.json
```
